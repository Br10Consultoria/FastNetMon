Identificação do assinante (login por IP e horário)

Escolha de onde vem o login de quem tinha um IP num horário — funciona com qualquer ERP. O recomendado é a API do ERP com um token só de consulta; o acesso direto ao banco (radacct ou SQL própria) fica como alternativa, sempre com usuário somente leitura. O endpoint precisa responder o histórico de conexões do IP (não só quem está conectado agora), para servir também às denúncias que chegam dias depois. Segredos (senha e cabeçalhos) nunca voltam para a página: campo vazio mantém o atual.
