Como usar

  • Backup agora: sudo systemctl start orbymon-backup
  • Ver o conteúdo de um backup (não altera nada): sudo bash /opt/orbymon/scripts/orbymon-restore.sh {{ folder }}/ARQUIVO
  • Restaurar: o mesmo comando com --yes (opcional --only etc|db|history|grafana). A configuração atual vai para /etc/orbymon.antes-restore-….
  • Cópia fora do servidor: ORBYMON_ARCHIVE_CMD em /etc/orbymon/retention-archive.conf (ex.: rclone copy {} remoto:orbymon/). Com /etc/orbymon/backup.key o arquivo sai cifrado (AES-256) — guarde a chave fora do servidor.
